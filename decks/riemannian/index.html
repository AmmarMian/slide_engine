Definition 1.1 — Smooth manifold
A smooth n-manifold is a Hausdorff topological space \mathcal{M} equipped with a smooth atlas \{(U_\alpha, \varphi_\alpha)\}: open charts \varphi_\alpha: U_\alpha \to \mathbb{R}^n whose transition maps are C^\infty.
Intuitively: locally looks like \mathbb{R}^n, but may curve globally.
When \mathcal{M} \subset \mathbb{R}^m is a smooth embedded submanifold we can work in ambient coordinates and restrict as needed.
Sphere
S^n = \{x \in \mathbb{R}^{n+1} : \|x\| = 1\}, dim n.
Rotation group
\mathrm{SO}(n) = \{Q : Q^\top Q = I,\, \det Q = 1\}, dim \tfrac{n(n-1)}{2}.
Stiefel manifold
\mathrm{St}(n,p) = \{X \in \mathbb{R}^{n\times p} : X^\top X = I_p\}, dim np - \tfrac{p(p+1)}{2}.
SPD cone
\mathcal{S}_{++}^n = \{A \in \mathbb{R}^{n\times n} : A \succ 0\}, dim \tfrac{n(n+1)}{2}.

Definition 1.2 — Tangent space
The tangent space at x \in \mathcal{M} is
T_x\mathcal{M} = \bigl\{\, \dot\gamma(0) : \gamma\text{ smooth curve},\, \gamma(0)=x \,\bigr\}
For embedded \mathcal{M}\subset\mathbb{R}^m this is a linear subspace of \mathbb{R}^m.
Sphere: T_x S^n = \{v \in \mathbb{R}^{n+1} : x^\top v = 0\}.
Definition 1.3 — Riemannian metric
A smooth family of inner products g_x : T_x\mathcal{M} \times T_x\mathcal{M} \to \mathbb{R}, symmetric and positive-definite for all x.
Sphere S^n
g_x(u,v) = u^\top v.
SPD \mathcal{S}^n_{++}
g_A(U,V) = \mathrm{tr}(A^{-1}UA^{-1}V).
Stiefel \mathrm{St}(n,p)
g_X(\Delta_1,\Delta_2) = \mathrm{tr}(\Delta_1^\top(I - \tfrac{1}{2}XX^\top)\Delta_2).

Theorem 1.4 — Riemannian gradient (Riesz)
There exists a unique vector field \mathrm{grad}\,f satisfying
\bigl\langle\, \mathrm{grad}\,f(x),\, v \,\bigr\rangle_x = Df(x)[v] \qquad \forall\, v \in T_x\mathcal{M}.
For embedded manifolds, \mathrm{grad}\,f(x) = \mathrm{Proj}_{T_x\mathcal{M}}\!\left(\nabla f(x)\right).
\mathrm{grad}\,f(x)\big|_{S^n} = \nabla f(x) - \bigl(x^\top \nabla f(x)\bigr)\,x
(1.1)
Project the Euclidean gradient onto the tangent plane T_x S^n = x^\perp by subtracting the normal component.
Stiefel manifold
\mathrm{grad}\,f(X) = \nabla f(X) - X\,\mathrm{sym}\!\bigl(X^\top\nabla f(X)\bigr)
SPD cone
\mathrm{grad}\,f(A) = A\,\nabla f(A)\,A.
Key property
Always in T_x\mathcal{M} — a valid descent direction for moving along the manifold.

\min_{x\,\in\,\mathcal{M}}\; f(x)
(P)
f:\mathcal{M}\to\mathbb{R} is smooth. The constraint is structural — not a penalty or Lagrange multiplier.
Why not lift to \mathbb{R}^m? Projected gradient descent loses curvature information; lifted problems are non-convex even when f is geodesically convex on \mathcal{M}.
Definition 2.1 — Geodesic convexity
f is geodesically convex if for every geodesic \gamma:[0,1]\to\mathcal{M}, f(\gamma(t)) \;\leq\; (1-t)\,f(\gamma(0)) + t\,f(\gamma(1)).
Examples in ML
PCA on a Grassmannian, orthogonally-constrained networks (WW^\top = I), covariance estimation on \mathcal{S}^n_{++}, Fréchet mean on hyperbolic space.
Fundamental difficulty
The update x + \alpha v leaves \mathcal{M}. A retraction R_x maps tangent vectors back onto the manifold.
Stationarity condition
x^\star is critical iff \mathrm{grad}\,f(x^\star) = 0.

Definition 2.2 — Exponential map
For v \in T_x\mathcal{M}, let \gamma_v be the unique geodesic with \gamma_v(0)=x,\; \dot\gamma_v(0)=v. Then \mathrm{Exp}_x(v) := \gamma_v(1) \;\in\; \mathcal{M}.
Sphere: \mathrm{Exp}_x(v) = x\cos\|v\| + \frac{v}{\|v\|}\sin\|v\|.
Definition 2.3 — Retraction
A smooth map R_x : T_x\mathcal{M} \to \mathcal{M} with R_x(0_x) = x \quad\text{and}\quad DR_x(0_x) = \mathrm{id}_{T_x\mathcal{M}}. First-order approximation to \mathrm{Exp}_x.
Sphere
R_x(v) = (x+v)/\|x+v\|. Cheap, exact.
Stiefel (QR)
R_X(\Delta) = \mathrm{qf}(X + \Delta), O(np^2).
Stiefel (Cayley)
R_X(\Delta) = (I - \tfrac{1}{2}W)^{-1}(I + \tfrac{1}{2}W)\,X.

Algorithm 1 — RGD with retraction
Input: f,\;\mathcal{M},\; x_0 \in \mathcal{M},\;\{\alpha_k\}
For k = 0, 1, 2, \ldots
  Compute g_k = \mathrm{grad}\,f(x_k) \in T_{x_k}\mathcal{M}
  If \|g_k\| \leq \varepsilon: return x_k
  Set x_{k+1} = R_{x_k}(-\alpha_k\, g_k)
EndFor
x_{k+1} = R_{x_k}\!\bigl(-\alpha_k\,\mathrm{grad}\,f(x_k)\bigr)
(2.1)
Step-size rules
Constant \alpha, backtracking Armijo, Barzilai–Borwein — all port from Euclidean GD.
Vs. projected gradient
PGD uses the ambient gradient. RGD uses the intrinsic gradient — cheaper and more accurate.
Parallel transport
For momentum methods (CG, L-BFGS), past gradients must be transported to T_{x_k}\mathcal{M} via \mathcal{T}_{x_{k-1}\to x_k}.

Theorem 2.4 — Convergence of RGD (Zhang & Sra, 2016)
Let f be geodesically convex and L-smooth, \alpha \leq 1/L. Then
\frac{1}{K}\sum_{k=0}^{K-1}\|\mathrm{grad}\,f(x_k)\|^2 \;\leq\; \frac{2\bigl(f(x_0)-f^\star\bigr)}{\alpha K}.
Under geodesic strong convexity (parameter \mu > 0):
d(x_k, x^\star)^2 \;\leq\; \left(1 - \alpha\mu\right)^k d(x_0,x^\star)^2.
Geodesic convex
O(1/K) rate. Same as Euclidean convex case.
Strongly convex
Linear rate (1-\alpha\mu)^k. Condition number \kappa = L/\mu.
Nonconvex
O(1/K) to first-order critical point.

Algorithm 2 — Riemannian CG (Polak–Ribière)
x_{k+1} = R_{x_k}(\alpha_k d_k)
\beta_k^{\mathrm{PR}} = \tfrac{\langle g_{k+1},\, g_{k+1} - \mathcal{T}g_k \rangle}{\|g_k\|^2}
d_{k+1} = -g_{k+1} + \beta_k^{\mathrm{PR}}\,\mathcal{T}d_k
\mathcal{T} = parallel transport from T_{x_k}\mathcal{M} to T_{x_{k+1}}\mathcal{M}.
Algorithm 3 — Riemannian Trust Region
Sub-problem in the tangent space: \min_{v \in T_{x_k}\mathcal{M},\; \|v\| \leq \Delta_k} m_k(v) where m_k(v) = f(x_k) + \langle g_k, v\rangle + \tfrac{1}{2}\langle H_k v, v\rangle. Update: x_{k+1} = R_{x_k}(v_k^\star).
RTR achieves quadratic local convergence. Implemented in Manopt and Pymanopt.

Definition 3.2 — Grassmann manifold
\mathrm{Gr}(p,n) = \mathrm{St}(n,p)\,/\,\mathrm{O}(p) Quotient by right \mathrm{O}(p)-action. Dimension p(n-p).
PCA on Grassmann
Minimize \|X - UU^\top X\|_F^2 over [U] \in \mathrm{Gr}(p,n).
Orthogonal RNNs
W \in \mathrm{SO}(n) prevents vanishing/exploding gradients. Train via Cayley retraction.
Low-rank factorization
Matrix completion on \mathrm{St}(n,r) \times \mathrm{St}(m,r). Avoids nuclear-norm relaxation.

Definition 3.3 — SPD manifold
\mathcal{S}^n_{++} = \bigl\{A \in \mathbb{R}^{n\times n} : A = A^\top,\; A \succ 0\bigr\} Open cone; T_A\mathcal{S}^n_{++} = \mathbb{S}^n.
Affine-invariant metric & geodesic
g_A(U,V) = \mathrm{tr}(A^{-1}U\,A^{-1}V)
(3.1)
\gamma(t) = A^{1/2}\!\left(A^{-1/2}BA^{-1/2}\right)^{\!t}\!A^{1/2}
(3.2)
Log-Euclidean metric
d(A,B) = \|\log A - \log B\|_F. Flat space via matrix log.
Fréchet mean
\bar A = \arg\min_A \sum_i d(A, A_i)^2. Arises in BCI, DTI-MRI, radar.
Bures–Wasserstein
Optimal-transport metric on Gaussians. Used in GAN training and domain adaptation.

Intrinsic vs. extrinsic
Riemannian methods respect the manifold's geometry — no projections, no constraint violations, faster convergence.
Retraction = the key tool
Cheap retractions (normalization, QR, Cayley) make RGD competitive with Euclidean GD per-iteration.
Same convergence theory
O(1/K) convex, linear strongly-convex — Euclidean rates port with d(\cdot,\cdot) replacing \|\cdot\|.
Geometry opens new doors
Hyperbolic embeddings, SPD networks, and Grassmann PCA are naturally Riemannian.
Manifolds are not obstacles.
They are the right domain.
— paraphrasing Absil, Mahony & Sepulchre (2008)
